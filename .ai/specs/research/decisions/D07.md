# D07 — CI gate first; store/auth migration slices scheduled separately
- Date, owner: 2026-09-21, Kamil Mastalerz (decided in the discovery session)
- Context and the options weighed: the readiness plan defers migration/production implementation until "a separate decision". Candidates for the first slice: CI workflow, Google OAuth sign-in, moving the prototype onto the api service.
- Decision and why: the first implemented slice is a CI workflow running the repository's six-command validation gate on every PR. It is small, touches no protected surface, and unblocks the pipeline's ci-monitoring and merge gates (the repository has no CI today). The Postgres/S3/auth migration remains scheduled, not started.
- Consequences, and what would make us revisit it: migration implementation starts only via a separately scheduled slice after this. Revisit if CI lands and the team reprioritizes.
- Status: active
