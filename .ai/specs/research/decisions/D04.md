# D04 — Clean start: no import of existing local data
- Date, owner: 2026-09-21 (decision recorded in docs/production-readiness-plan.md §5, written 2026-09-04); ownership confirmed by Kamil Mastalerz in the discovery session
- Context and the options weighed: migrating `state.json`/`.eml` history into the new store vs. starting fresh.
- Decision and why: existing local JSON and `.eml` files are not imported and remain untouched. On first connection the IMAP cursor is recorded (`UIDVALIDITY`, `UIDNEXT - 1`) and sync continues from there; a `UIDVALIDITY` change halts sync pending a deliberate re-establishment. At launch only the current test-mailbox integration is carried over.
- Consequences, and what would make us revisit it: no data-migration code to build or trust; the local prototype keeps its independent history. Revisit if historical conversations become a requirement.
- Status: active
